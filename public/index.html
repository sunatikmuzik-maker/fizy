Как хранятся данные

Сервер хранит логин, хеш пароля с солью, хеш кода восстановления и записи журнала. Cookie нужен для входа и не используется для рекламы.

Сделки привязаны к аккаунту. Другие пользователи не получают к ним доступ через сайт. Администратор хостинга технически может иметь доступ к базе и её резервным копиям. Записи не защищены сквозным шифрованием.

Внешние сервисы получают запросы загрузки библиотеки графиков и, только после твоего согласия, файлов модели ИИ. Текст вопросов не отправляется облачной модели. Instagram открывается только по ссылке.

Активная сессия действует 7 дней. Удаление аккаунта удаляет данные из рабочей базы; срок хранения копий определяется владельцем сайта.

Не вводи в заметки ключи доступа, платёжные реквизиты и чужие персональные данные.
